# Abdul Wasay - Front-End & CMS Developer Portfolio

A sleek, modern, high-performance portfolio website built with **React**, **Vite**, and vanilla **CSS Design System**, featuring:
- **30+ Curated Real-World Client Projects** across **WordPress, WooCommerce, Shopify, Wix Studio, and Webflow**.
- **Interactive Live Filtering & Instant Search** across industries and technologies.
- **Modern Dark-Mode Aesthetics** with ambient glowing gradients, glassmorphism cards, and micro-interactions.
- **Conversion-Optimized Contact & Services Sections**.

## ⚡ Deployment to Vercel (1-Click)

### Method 1: Via Vercel Web Dashboard (Recommended)
1. Push this project to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: complete Abdul Wasay portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
3. Click **"Add New"** > **"Project"**.
4. Select your newly pushed repository.
5. Vercel will automatically detect **Vite**:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
6. Click **Deploy**. In under 60 seconds, your portfolio will be live with free SSL!

### Method 2: Via Vercel CLI
```bash
npx vercel
```
Follow the interactive prompts and your site will be live immediately.
